Pareja tipográfica 2

Bricolage Grotesque · Figtree · Azeret Mono

La grotesca con trampas de tinta que el chrome actual ya tiene instalada, llevada a su registro de display (opsz 96, wdth 90: condensa un poco y afila las esquinas), con Figtree como cuerpo, una geométrica amable de ojo alto, y Azeret Mono, una mono con personalidad, para etiquetas. Es la pareja más «urbana» de las tres.
