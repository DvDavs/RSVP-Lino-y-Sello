las `aRevisar` de las tres plantillas son o bien (a) URLs externas de imagen/audio del bucket S3 legado
que este entorno no descarga (el proxy bloquea bancos de imágenes) — quedan con `provenance:"empty"`

emiten. **Ninguna** de las tres trae una `aRevisar` de tipo "colisión de fuentes" (a diferencia de

estructura y contenido de demostración, no arte final" del encargo: el hueco de imagen queda listo
