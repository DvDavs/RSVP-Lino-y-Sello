# 3c-1 → bloques 1, 2 y 3 — `@invitaciones/tokens` y la galería `/design`

## Qué hay ya
`frontend/packages/tokens`: fuente TS → `generated/tokens.css` (todas las `--ui-*`, `:root` +
`[data-theme="light"|"dark"]`) → `generated/tailwind.css` (`@theme inline`, solo roles semánticos);
los dos CSS commiteados, con prueba que los compara byte a byte con la fuente. La galería vive en
`apps/web/app/(chrome)/design/**` (índice y `/design/tokens`, con conmutador de tema).

- **Contraste** `luminancia()`, `contraste()`, `verificarParejas(paletas?, sabotaje?)`, `tablaContraste()`, `semanticaResuelta(id)`.
- **Tipografía** `FAMILIAS`, `PESOS`, `ESCALA`, `ROLES_TIPOGRAFICOS` (15), `clampTipografico()`, `variacionesDe()`, `enMovil()`, `enEscritorio()`, `varia()`.
- **Espacio, forma y movimiento** `ESPACIO`, `RADIOS`, `RADIOS_SEMANTICOS`, `SOMBRAS`, `CONTENEDOR`, `Z_INDEX`, `BREAKPOINTS`, `DURACIONES`, `CURVAS`, `USO_DURACION`, `USO_CURVA`.
- **Emisión** `generarTokensCss()`, `generarTailwindCss()`, `FICHEROS_GENERADOS`, `varDe()` · tipos `Token`, `TokenColor`, `TokenTipografico`, `TokenEspacio`, `TokenMovimiento`.
- **Scripts** `verify-contrast` (`--activa`, `--json`, `--sabotear=rol=#hex`), `emit:css` (`--check`), `escalas` (`--md`); `build` = verify + emit + `tsc`.

## Cómo se consume
```css
@import "tailwindcss";
@import "@invitaciones/tokens/tokens.css";
@import "@invitaciones/tokens/tailwind.css";
```
`data-theme="light|dark"` en `<html>` (también funciona anidado). Utilidades: `bg-ui-primary`,
`text-ui-on-primary`, `border-ui-divider`, `ring-ui-focus`, `rounded-ui-{control,card,media,hero,pill}`,
`shadow-ui-{1,2,color}`, `max-w-ui-page`, `font-ui-{display,text,label}`, `text-ui-<rol tipográfico>`,
`ease-ui-{out,in-out,spring,linear}`. Las **duraciones** no son utilidades (Tailwind 4 no tiene ese
espacio de nombres): `duration-[var(--ui-dur-2)]`; los **pasos de escala**, solo variable
(`var(--ui-primary-300)`) para las formas.

## Convivencia con el chrome viejo (LEER ANTES DE PINTAR ALGO NUEVO) — ADR-3C-1-02
Los `@import` van antes del `@theme` provisional, así que en los nombres repetidos **gana el valor
viejo**: `bg-ui-surface`, `text-ui-ink`, `text-ui-ink-muted`, `border-ui-border`, `ring-ui-focus`,
`bg-ui-accent`, `rounded-ui-{control,card,media,pill}`, `shadow-ui-{1,2}` y `font-ui-display` siguen
siendo los de la fase 3. Fuera de `/design`, usa los nombres que no chocan (`bg-ui-primary`,
`bg-ui-surface-raised`, `text-ui-on-primary`, `bg-ui-primary-soft`, `text-ui-link`…) o el puente de
`design/galeria.module.css`. **El bloque 3, al borrar el `@theme` viejo, borra también ese puente.**
