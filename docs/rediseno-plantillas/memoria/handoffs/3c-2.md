# 3c-2 → quien consuma tipografía del sistema (fase 3-C, bloque 1)

Fuente completa: `11 §2`, `ADR-3C-2-01`, bitácora `bitacora/3c-2.md`. Worktree: `wt-3c/3c-2` (rama `wt/3c-2`, sin commit).

## Qué se entrega

1. **Fuentes autoalojadas** (`packages/ui/src/fonts/`): `fonts.css` (seis `@font-face` — 3 familias × latino/latin-ext, `font-display: swap`, `unicode-range` de fontsource) y `preload.ts` (manifiesto único: `FUENTES_AUTOALOJADAS`, `RUTAS_PRECARGA`, `PRESUPUESTO_PRIMERA_VISTA_BYTES = 177188`). Familias: **Fraunces** `full` (display, ejes wght+opsz+SOFT+WONK), **Onest** (texto), **Red Hat Mono** (etiqueta) — `@fontsource-variable/{fraunces@5.3.0,onest@5.3.1,red-hat-mono@5.3.0}`, OFL-1.1.
2. **Escala tipográfica** (`packages/ui/src/styles/typography.css`): 15 clases (`display-2xl…display-sm`, `heading-lg…heading-sm`, `text-lg…text-xs`, `label-lg…label-sm`) más `.prose` y `.numeros-tabulares`. Responsivo 390→1024+ con `clamp()` (tamaño) y `@media (min-width:1024px)` (interlineado/tracking que cambian). Cada declaración es `var(--ui-…, valor-de-doc)` — ver "Riesgo" abajo.
3. **`packages/ui/src/estilos.css`** (hoja raíz, ahora completa): `@import "@invitaciones/tokens/tokens.css"; @import "./fonts/fonts.css"; @import "./styles/typography.css";`.
4. **`packages/ui/scripts/copiar-fuentes-publicas.ts`**: copia los 6 `.woff2` a `apps/web/public/fonts/`; corre en el `build` del paquete (`node scripts/copiar-fuentes-publicas.ts && tsc --noEmit`).
5. **`apps/web`**: `app/(chrome)/globals.css` añade `@import "@invitaciones/ui/estilos.css";` (los tres `@import` viejos de inter/bricolage/outfit SIGUEN ahí, no se tocan); `app/(chrome)/layout.tsx` añade `<head>` con un `<link rel="preload" as="font" type="font/woff2" crossOrigin="anonymous">` por cada ruta de `RUTAS_PRECARGA` (hoy una: Fraunces latino); `app/(chrome)/design/tipografia/page.tsx` (especímenes completos, es-MX).
6. `packages/ui/src/index.ts` reexporta todo `./fonts/preload.ts` (`import { RUTAS_PRECARGA, FUENTES_AUTOALOJADAS } from "@invitaciones/ui"`).

## Cómo se consume

```ts
import { RUTAS_PRECARGA, FUENTES_AUTOALOJADAS } from "@invitaciones/ui";
```
```css
@import "@invitaciones/ui/estilos.css"; /* trae tokens + @font-face + utilidades */
```
```html
<p class="display-lg">Título</p>
<p class="text-md">Cuerpo <strong>en negrita (650)</strong>.</p>
<p class="label-md">PASO 2 DE 4</p>
```
Regla dura, con prueba: ninguna clase `display-*`/`heading-*` usa la familia de texto o etiqueta, ni al revés (`packages/ui/test/tipografia.test.ts`).

## Riesgo / qué falta reconciliar

- `estilos.css` importa `@invitaciones/tokens/tokens.css`, que en este worktree NO existía (3C-1 en paralelo) — se creó un **placeholder** en `packages/tokens/generated/tokens.css` (solo las 3 vars de familia) para que el build no rompiera; **debe sustituirlo** el `build-css.mjs` real de 3C-1 al integrar (misma ruta, gana siempre esa versión).
- Los nombres `--ui-<rol>-size/-leading/-tracking/-weight` de `typography.css` son una convención propia (el doc 11 no los fija); si 3C-1 usa otros nombres, el aspecto no cambia (el `clamp()` de reserva sigue siendo la fuente real), pero esas variables no quedan conectadas al sistema de tokens hasta alinear nombres. Detalle en `preguntas-abiertas.md § Fase 3-C · 3c-2`.
- `apps/web/public/fonts/*.woff2` es un artefacto de build (lo escribe el `build` de `@invitaciones/ui`); no se decidió si se ignora en git o se versiona.
- `ss01` no se aplicó (sin `fonttools` en el entorno para verificar que las tres fuentes lo declaran); sí se aplicó `tabular-nums`.
- `packages/ui/src/shapes/` no se tocó (es de 3C-4).

## Integración (3C-2b)

Los dos huecos de `bitacora/3c-rev-2.md` quedan cerrados. (1) `typography.css` ya NO tiene nombres
de variable propios: cada declaración usa `var(--ui-<nombre-real>, reserva)` con los nombres que
`packages/tokens/generated/tokens.css` emite de verdad (`--ui-text-<rol>`, `--ui-leading-<rol>`,
`--ui-tracking-<rol>`, `--ui-weight-<rol>`, `--ui-variacion-<rol>` para los 15 roles,
`--ui-font-{display,text,label}`, `--ui-weight-texto-fuerte` para el énfasis); las reservas se
corrigieron para coincidir byte a byte con el token (el `.display-2xl` de escritorio pasó a
1,02/-0,04em). `test/tipografia.test.ts` ahora parsea `tokens.css` y `typography.css` y cae si un
rol referencia una variable que los tokens no emiten o si la reserva diverge. (2) Metric override
real: `packages/ui/scripts/metric-override.ts` (con `@capsizecss/metrics`, devDependency exacta)
calcula `ascent-override`/`descent-override`/`line-gap-override`/`size-adjust` de "Fraunces
Fallback" (vs Georgia), "Onest Fallback" (vs Arial) y "Red Hat Mono Fallback" (vs Courier New) con
la misma fórmula que usa `next/font`, y los escribe en `fonts.css` entre marcadores
(`test/metric-override.test.ts` compara lo commiteado con lo recalculado). Esas tres familias
quedan en la pila `--ui-font-{display,text,label}` de `packages/tokens/src/tipografia.ts`, justo
detrás del nombre real (`tokens.css`/`tailwind.css` regenerados). Cifras y comandos literales en
`bitacora/3c-2b.md`. Compuertas del monorepo en verde (tokens 55/55, ui 403/403, web 386/386,
typecheck y lint limpios); `pnpm --filter @invitaciones/tokens run build` deja `generated/`
idéntico a lo commiteado.
