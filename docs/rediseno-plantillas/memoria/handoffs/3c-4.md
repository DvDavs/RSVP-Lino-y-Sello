# 3c-4 → quien componga con formas — API de `@invitaciones/ui/shapes`

Fuente: `diseno/11-sistema-de-diseno.md §3` y `ADR-3C-0-03`; decisiones propias en `ADR-3C-4-01`.
Galería viva: `/design/formas`. Capturas: `evidencia/fase-3c/bloque-1/formas-*.png`.

## 1. Cómo se consume

```tsx
import { Rays, Image, Composition, Pill } from "@invitaciones/ui";
// La hoja llega por `@invitaciones/ui/estilos.css` (el `@import "./shapes/shapes.css"` lo añade el
// orquestador). Antes de eso: import "@invitaciones/ui/shapes/shapes.css".
```

Props comunes de las formas SVG: `tone`, `rotate`, `scale`, `className`, `style`, `breathe`, `drift`.
`tone` es el tipo `Tono` y **solo** admite tokens (`"primary-soft"`, `"support-2"`…): no hay manera de
pasar un hex. Todas son decorativas (`aria-hidden`); para anunciar una, `decorative={false}`, y entonces
el tipo **exige** `title`. Todas son Componentes de Servidor (ningún hook dentro).

## 2. Catálogo

| componente | props propias | notas |
|---|---|---|
| `Rays` | `density=12` `radius=120` `origin="50% 50%"` `backdrop?` | `backdrop` pinta el segundo paso del mismo matiz. |
| `Stripes` | `angle=-24` `gap=18` `width=9` `backdrop?` `id?` | emite `<pattern>`. |
| `WaveDivider` | `from` `to` `profile="suave"\|"marcada"\|"doble"` `layers=1\|2` `tones=[Tono]` `flip` `height=90` | tres curvas FIJAS; `doble` implica `layers=2`. |
| `Blob` | `seed=1` `points=7` `amplitude=0.22` `radius=42` | mismo `seed`, mismo `path`, en servidor y cliente. |
| `Triangle` | `radius=12` | `radius={0}` = el vértice duro del moodboard. |
| `RotatedSquare` | `radius="sm"\|"md"\|"lg"\|"xl"` `rotate=12` `scale=1` | el lado se inscribe: girado no se sale del bloque. |
| `Seal` | `points=12` `amplitude=4` `radius=44` | `r(θ) = R + a·cos(nθ)`. |
| `Pill` | `tone="primary"\|"support-1"\|"support-2"\|"accent"` `dot` `children` | **no** decorativa: lleva texto. Pareja fondo/texto verificada y cerrada. |
| `ColorShadow` | `tone="support-2"` `offset={{x:8,y:8}}` `radius="lg"` `border` `as` | envoltorio. **Una por vista**, nunca con sombra difusa. |
| `Image` | `mask="radius-lg"\|"blob"\|"arch"\|"seal"\|"rotated"` `seed` `points` `amplitude` `rotate` `radius` `src?` `alt` `ratio="1 / 1"` `imageId?` `tones?` `id?` `children?` | `children` para `next/image`; sin `src` ni `children` pinta el placeholder. |
| `Placeholder` | `label` (obligatorio) `imageId?` `tones?` `decorative?` | se anuncia con `label`; emite `data-imagen-pendiente={imageId}`. |
| `Composition` | `shape` `place` `size` `height?` `offset` `secondaryShape?` `as` `className` `contentClassName` | recorta, separa `z-index` y oculta la capa del árbol accesible. |

`place`: `centro` `cubrir` `arriba-izquierda` `arriba-derecha` `abajo-izquierda` `abajo-derecha`
`izquierda` `derecha`. La capa es cuadrada (`size` = ancho) salvo que se dé `height`.

También se exportan la geometría (`blob`, `sello`, `rayos`, `poligonoRedondeado`, `triangulo`,
`cuadradoRedondeado`, `ladoInscrito`, `arco`, `ONDAS`, `prng`), las máscaras (`definirMascara`,
`MASCARAS`), las utilidades de `base.ts` (`color`, `clases`, `accesibilidad`, `idEstable`,
`claseDeForma`, `transformacion`) y `useReducedMotion()`.

## 3. Reglas que el código YA hace cumplir (las demás son de revisión, `11 §3.4`)

- **R3**: `Composition` recorta (`overflow: hidden`) y pone la forma en `z-index: 0`, el contenido en `1`; no saques un párrafo, un campo o un botón del `children` de la composición.
- **R1**: `secondaryShape` se limita a `45 % × 45 %` del bloque (≈ 20 % del área).
- **R4**: `Image` siempre aplica `clip-path`; `radius-lg` nunca baja de 24 px.
- **R7**: `breathe`/`drift` solo ponen una clase; el apagado vive en `shapes.css` (`no-preference` + `reduce`), no en el componente.
- **R6** (el 500 solo en formas grandes) y **R2** (contraste de matiz) siguen siendo de revisión humana.

## 4. Qué falta / qué tiene que hacer quien integre

1. Añadir `@import "./shapes/shapes.css";` a `packages/ui/src/estilos.css` (propiedad de 3C-2).
2. En `app/(chrome)/design/formas/page.tsx`, en cuanto `globals.css` importe `@invitaciones/ui/estilos.css`: **borrar** `TOKENS_PROVISIONALES` con su `<style>` (45 líneas marcadas) y el `import "@invitaciones/ui/shapes/shapes.css"`.
3. Sustituir el icono en línea de `Placeholder.tsx` por `<GaleriaIcon />` de `@invitaciones/icons` (hay un `TODO` en el archivo) y el `IconoChispa` de la galería por `<ChispaIcon />`.
4. Nombres de token supuestos, a confirmar: `--ui-text-xs`, `--ui-font-{text,label}`, `--ui-dur-respira`, `--ui-radius-{sm,md,lg,xl,pill}`, `--ui-space-{2,3}`. Si cambian, la píldora hereda el tipo del bloque: degrada, no rompe.
5. Fuera de alcance de este bloque: `/design` (índice y `layout.tsx`), `e2e/design.spec.ts` con `toHaveScreenshot` (`ADR-3C-0-06`) e ilustraciones de estados vacíos (`11 §4.3`).
