Fuente: `11 §5`, `handoffs/3c-0.md` (fórmula del anillo de foco). Decisiones propias en
`ADR-3C-B2F1-01`. Bitácora completa: `bitacora/3c-b2-f1.md`. Sin commits, worktree `wt-3c/b2-f1`.

## Cómo se consume

```tsx
import { Button, Field, Input, Textarea, Select, Combobox, RadioGroup, Checkbox, Switch, Chip } from "@invitaciones/ui";
```

`Field` envuelve UN control (clona `id`/`aria-invalid`/`aria-describedby` sobre él):

```tsx
<Field label="Correo electrónico" hint="El mismo con el que contrataste">
  <Input type="email" placeholder="nombre@correo.com" />
</Field>
```

## API por componente

- **`Button`** `variant="primario|secundario|terciario|icono|peligro|acento"` `size="sm|md|lg"` (36/44/
  52) `loading` `loadingText` `asChild` (Slot, para `<a>`). Icono solo → dar `aria-label` (el tipo no lo impone).
- **`Field`** `label` `hint` `error` `required` `id?`; `children` es UN elemento que acepte
  `id`/`aria-invalid`/`aria-describedby` (todos los de este paquete lo hacen).
- **`Input`** `invalido?: boolean` (o `aria-invalid`) + props nativas de `<input>`. 46 px de alto.
- **`Textarea`** ídem + `limite?: number` (contador `n/límite`, **aparece al 80 %** del límite, no
  antes). Alto mínimo 96 px.
- **`Select`** (≤ 5 opciones) `opciones: {value,label,disabled?,motivo?}[]` `placeholder?` `invalido?` +
  props de Radix Select (`value`/`onValueChange`/`open`…). Disparador de 44 px.
- **`Combobox`** (> 5 o con búsqueda) `opciones: {value,label:string,disabled?}[]` `value?`
  `defaultValue?` `onValueChange?` `placeholder?` `textoSinResultados?`. **Sin Radix Popover** (ver ADR). 46 px.
- **`RadioGroup`** `opciones: {value,label,meta?,disabled?}[]` + props de Radix RadioGroup. Radios de
  26 px; fila ≥ 44 px (clic en el texto selecciona).
- **`Checkbox`** `label?` `meta?` + props de Radix Checkbox. 26 px; con `label`, fila ≥ 44 px.
- **`Switch`** `label?` + props de Radix Switch. Pista 48×28, bolita 22.
- **`Chip`** `tono="neutro|exito|aviso|peligro|info|acento"` `seleccionado?: boolean` (→
  `aria-pressed`) `icono?` `onCerrar?` `labelCerrar?` (nombre accesible del cierre — `<button>` HERMANO,
  nunca anidado). 34 px de alto.

## Por qué el anillo de foco y las medidas van por `style` en línea, no por clase Tailwind

`packages/ui` no compila Tailwind en sus propias pruebas; jsdom tampoco evalúa `:focus-visible` contra
una hoja real (verificado). Cada componente calcula su `box-shadow`/tamaño en JS con las utilidades de
arriba y lo aplica como `style`; el resto del aspecto (color, radio, tipografía) sigue siendo Tailwind
del preset semántico. Detalle y alternativas descartadas: `ADR-3C-B2F1-01`.
