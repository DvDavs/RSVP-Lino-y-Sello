## Nota de entorno para quien siga en este worktree

`pnpm --filter … run convertir -- <id>` reenvía el `--` literal al script en esta instalación de
pnpm y el CLI lo rechaza (`Órdenes: cobertura | convertir …`, salida 2). Usar
`npx tsx src/cli.ts <id> [--dry-run] [--decision id=opcion] [--forzar]` dentro de
`frontend/packages/migration-legacy/` en su lugar — es el mismo comando que ejecuta el script.
`pnpm plantilla check` resuelve contra `INIT_CWD`: desde `frontend/` pasar `templates/<slug>/1.0.0`,
no `frontend/templates/<slug>/1.0.0` (si no, `TPL_PACKAGE_NOT_FOUND`).
