# Referencia visual: gigsalad.com (capturas móviles, 2026-09-05)

Aportadas por el dueño como **referencia de lenguaje visual**, no como algo que copiar. Lo que se adopta es la *actitud*: color vivo pero elegante, formas geométricas y orgánicas como recurso de composición, iconografía propia, controles a medida y una jerarquía tipográfica muy clara.
